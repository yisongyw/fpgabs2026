# FS03_DR1V90GEG_img_process_create2_sc520 工程说明

> 本工程在 `FS03_DR1V90GEG_img_process_create1` 基础上做**纯 PL 创新**：
> 完整移除 PS（处理器系统）相关代码、只用 PL 资源，保留原工程全部图像处理功能，
> 并新增“自动演示巡检（Auto-Demo Patrol）”等纯 PL 创新设计。
> 外设仅使用本仓库已出现的 **TM1638 数码管+LED+按键模块、小拨码开关模块、有源蜂鸣器、UART**，
> 未引入任何仓库之外的其它外设。

---

## 1. 工程概况

| 项 | 内容 |
| --- | --- |
| 工程名 | `FS03_DR1V90GEG_img_process_create2_sc520` |
| 开发板 | 安路 **FS03 / DR1V90GEG484**（-2，DR1 系列） |
| 输入 | SC500 1080p（实际 720p60）MIPI CSI-2 摄像头 |
| 输出 | HDMI 720p60（安路 HDMI TX IP，RGB888，25MHz 像素时钟） |
| 顶层 | `design_top_wrapper`（纯 PL，**无 PS、无处理器、无 DDR、无 DDR 控制器**） |
| 工程说明（原版参考） | `工程说明_create1原版.md`（create1 原文档）、`工程说明_HX原始.md`（HX 原始文档） |

**与 create1 的本质区别**（即本工程的创新点）：

1. **100% PL，彻底移除 PS**：create1 的“以太网命令通道”依赖 PS 硬核 GBE 经 EMIO GPIO 把 PC UDP
   命令桥接为 PL 虚拟按键（`I_ps_key_evt[3:0]`）及其 4 个占位引脚（H19/G15/C17/D18）、`ps_app/` 软件。
   本工程**删除以上全部内容**，命令切换完全由 PL 侧 UART 实现，工程结构更简单、功耗/资源更优。
2. **UART 短字符串命令作为全部 fpga 按键（非拨码开关）的等效切换通道**（与 HX1P35Aimg_process_create1
   设置一致，115200 8N1）：`K1`~`K4` 四个命令分别对应四个物理按键，作为“保险”备份切换手段。
3. **新增纯 PL 创新模块 `auto_demo_ctrl`（Auto-Demo Patrol）**：UART 发送 `DEMO` 命令即可开关
   “自动演示巡检”，由 PL 周期性产生风格+1/阈值+1 脉冲，自动遍历全部算法组合，并用 TM1638 LED
   跑马灯指示状态，便于现场答辩与无人值守演示。

## 3. 功能

全部沿用 create1 的图像处理功能（仅去掉 PS 以太网命令通道，UART 命令通道保留并增强）：

1. **视频通路**：MIPI CSI-2 → ISP（去马赛克/RAW→RGB/去噪/白平衡/Gamma/720p 缩放）→
   OSD 状态层 → HDMI TX → 显示器。
2. **图像处理算法（按键/拨码开关/UART 切换）**：
   - `SW1` 使能 Sobel 边缘检测；`SW2` 使能灰度；`SW3` 使能二值化；`SW4` 使能状态层文本。
   - `K1` 数码管显示切换（阈值/帧率/延时/ROI 坐标/分类序号…）；`K2` 二值化阈值 +1；
     `K3` 画质风格 +1（原图→灰度→边缘→二值→直方图均衡→…共 16 档）；`K4` OSD 开关。
   - `DEMO`（UART）开/关自动演示巡检。
3. **ROI 运动目标检测与分类**：帧差 → 形态学 → 连通域 → 质心/面积/宽高 → 8-32-64 MLP 分类
   （64 类，使用 30 个 DSP），OSD 叠加包围框 + 类别文字，命中时蜂鸣器报警（带消抖）。
4. **性能测量**：`fps_meter`（输入/输出帧率）、`latency_meter`（ISP→HDMI 端到端行延时）。
5. **TM1638 人机交互**：8 位数码管显示阈值/帧率/延时/状态；4 个 LED 状态指示；4 个按键控制。
6. **UART 双向通道（115200 8N1）**：
   - 命令（PC→FPGA）：`K1`~`K4`（对应四个物理按键）、`SD`/`CAM`/`LD`/`R?`，以及新增 `DEMO`。
   - 状态上报（FPGA→PC）：与 improve4 报文一致（帧率/延时/ROI/分类等）。

| 小拨码开关供电 | 12-pin | J11 上 | `O_sw_gnd[0..1]` / `O_sw_vcc[0..1]` | B19/B20 / D22/C22 | FPGA GPIO 提供 0/3.3V |

**引脚约束一致性**：`constraints_source/pin.adc` 由脚本在 FS03 基线 `pin.adc` 上逐行追加本项目新增引脚，
脚本含**逐行一致性检查**——基线 30 个引脚 100% 保留、新增 12 个外设引脚全部命中，且确认 H19/G15/C17/D18
不再出现。

## 5. 架构（纯 PL 数据/控制通路）

```
MIPI CSI-2 --> [DR1 MIPI IO + PHY PLL]
   --> csi_unpacket / raw10_unpacket / uial2axis
   --> isp_top_imgproc (demosaic / awb / gamma / 720p scale)
   --> img_proc_top (sobel / gray / bin / hist_eq / frame_diff / obj_detect / mlp)
   --> osd_* (mode/obj/motion/status overlay) + hdmi_mixer (Logo block-RAM)
   --> hdmi_tx --> HDMI

控制通路（全部 PL，无 PS）：
   TM1638 按键 / 拨码开关 / UART(K1~K4, DEMO)
      --> key_mode_delay_ctrl + auto_demo_ctrl (新增)
      --> 风格/阈值/OSD/报警 等算法参数
      --> OSD / 蜂鸣器 / 数码管
```

新增的 `auto_demo_ctrl` 与物理按键、UART 按键**共用同一条控制通路**
（`S_key_press -> key_mode_delay_ctrl`），只向 `r_hold1/r_hold2` 注入 1 拍脉冲，
**不引入新的跨时钟域问题、不改变任何像素主链路**，因此端到端延时保持不变。

## 6. 创新点（相对 create1 / 原赛题二方案）

### 6.1 纯 PL 化（去 PS 化）
- 移除 PS 硬核 GBE + EMIO GPIO 桥接、`I_ps_key_evt` 端口、4 个 PS 占位引脚、`ps_app/` 软件与
  相关文档章节。
- 命令切换统一收敛到 PL 侧 UART（与 HX 工程设置一致），工程更简洁、综合实现更快、功耗更低、
  跨时钟域更少（少一组 PS→PL 异步桥）。

### 6.2 UART 备份切换（题目要求）
- `K1`~`K4` 四个 UART 短字符串命令与四个物理按键**完全等效**（经 `uart_cmd_rx`→`cmd_parser`），
  满足“为保险另外添加通过 UART 从 PC 发送短字符串来实现和 fpga 所有按键（不是拨码开关）相同的切换功能”。

### 6.3 Auto-Demo Patrol（新增纯 PL 创新模块 `auto_demo_ctrl`）
- UART 发送 `DEMO` 开/关自动演示：使能后每 2 s 切换一次画质风格、每 1 s 扫一次二值化阈值，
  自动遍历全部 16×16 算法组合；TM1638 4 个 LED 做跑马灯、LED8 恒亮表示演示中。
- 实现代价极小（2 个 32 bit 计数器 + 4 bit 跑马灯寄存器 ≈ 数十 LUT / 百余 REG），
  资源占用可忽略，且不改变主链路延时。

## 7. 资源 / 时序 / 功耗优化

- **资源利用率均衡**：综合实现实测（见第 9 节，DR1V90GEG484）：LUT6 32.06%、SLICE 35.88%、
  ERAM 30.00%、DSP 12.50%、PLL 25.00%、GCLK 21.88%、IO 18.41%，各类型占用率均衡，
  最高仅约 36%，没有出现“某类资源几乎占满、另一类基本空闲”的情况。
- **功耗优化**：纯 PL 化去掉了 PS 处理器域与 PS→PL 异步桥的翻转；自动演示巡检仅在使能时
  增加极少翻转；平台侧 PLL 仍为 2 个，与 create1 一致。
- **时序/延时**：像素主链路（MIPI→ISP→OSD→HDMI）零算法插入、零额外缓冲，端到端行延时由
  `latency_meter` 实测（与 create1 一致）；新增 `auto_demo_ctrl` 运行于既有 100 MHz 控制域，
  不影响 75 MHz HDMI / MIPI 域时序。
